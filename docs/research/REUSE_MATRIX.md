## Own implementation audit

Main Phase 3 provides a useful known build/package baseline. The separately inspected
Phase 4 revision adds Organelle mapping and Granular Freezer; it remains unmerged.

Current constraints include fixed 44.1 kHz stereo/int16 adapter, mutex serialization,
single-instance libpd build configuration, scalar state and a 64-sample dry-path delay.
These are implementation limits, not evidence of universal patch support. The host
must not perform patch/filesystem work under the render lock. Existing validation is
valuable but does not establish multi-instance isolation, arbitrary external support,
complete state or sustained original-One timing under load.

## Licensing decisions before distribution

The project-wide license is undeclared at the inspected own revision. Choose an explicit
license before combining new upstream code. MIT/BSD notices must travel with binaries
and source; imported exceptions still matter. Granular Freezer's credited panning code
has GPL-2.0-or-later provenance despite the patch's broader BSD notice. Inspect exact
adapted files and satisfy compatible source/notice obligations. Samples, presets, models,
fonts and artwork have licenses independent of their engine. Do not redistribute an
Organelle library based solely on its repository-level license.

Camomile/PlugData GPL and their JUCE/fork dependencies require a complete dependency
review. Running hvcc as a compiler does not automatically impose the compiler's license
on every output; inspect generated runtime and linked code. New VST3 licensing does not
license legacy VST2 SDK files. The minimal hand-written ABI wrapper still needs its own
provenance review. No table row constitutes blanket legal permission.

## Loader prototype design refinement

[Concrete prototype design](../design/UNIVERSAL_LOADER_PROTOTYPE.md) retains private
Vanilla Pd and fixed Q-Links. Exclusive audio/worker ownership and a narrow Loader-only
wrapper adaptation are required new glue; the existing wrapper's blocking audio mutex
cannot simply be retained around a worker loader. No broad wrapper rewrite or visibility
change is justified. The exact [Pd symbol evidence](../design/PD_SYMBOL_BOUNDARY.md) and
[24-test classification](../design/UPSTREAM_TEST_FAILURE_CLASSIFICATION.md) replace the
previous unresolved failure diagnosis. GUI/CV/external support are not release prerequisites.
